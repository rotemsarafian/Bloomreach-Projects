# Bloomreach Projects

מאגר סקריפטי SQL לפרויקטי Bloomreach, לפי סביבת עבודה ו־BRP_ID.

## גישה והרשאות

הנראות הנדרשת היא **Private**: גישה לחברי הצוות המורשים בלבד. אין לפרסם נתונים, סודות או פרטי גישה בקבצים. הרשאת Write נדרשת למפתחים כדי לדחוף בראנצים ולמזג PRs.

## מבנה התיקיות

לכל אחת מ־25 רשומות הסביבה יש תיקייה ראשית ובה בדיוק שלוש תת־תיקיות:

- `views`: קובצי Views, בשם המדויק של ה־View עם סיומת `.sql`.
- `stored procedures`: סקריפטי Stored Procedures.
- `tables`: סקריפטי טבלאות.

תיקיות ריקות נשמרות ב־Git באמצעות `.gitkeep`. קובצי ה־SQL הראשוניים מכילים הערות בלבד; הגדרות ה־SQL טרם סופקו ואין לראות בהם סקריפטים מוכנים לפריסה.

## עבודה עם Git

1. מתחילים כל שינוי מ־`main` מעודכן ופותחים בראנץ׳ ייעודי, למשל `feature/update-view-name`.
2. שומרים את הסקריפט בתיקיית הסביבה והסוג המתאימים.
3. פותחים Pull Request מול `main` ומתארים את השינוי ואת הבדיקות שבוצעו.
4. מחבר ה־PR רשאי למזג אותו בעצמו לאחר השלמת העבודה; אין חובת אישור של חבר צוות אחר.

ראו [הנחיות תרומה](CONTRIBUTING.md).

## אכיפת המדיניות ב־GitHub

התיעוד אינו מגדיר הרשאות או הגנות בראנץ׳ בפועל. על מנהל הרפוזיטורי להגדיר את הנראות כ־Private ולהעניק גישה רק לצוות המורשה. יש להגדיר עבור `main` כלל המחייב Pull Request לפני מיזוג, עם **0 אישורים נדרשים**, ללא חובת CODEOWNERS או אישור נוסף לדחיפה האחרונה, וללא עקיפות למפתחים. יש לחסום force pushes ומחיקת `main`. הגדרות אלה טרם הוחלו באמצעות החיבור הנוכחי.
